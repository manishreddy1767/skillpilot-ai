# What you can say or type

Type these in the Assistant, or press a microphone and say them. They run at once, offline, even with the
AI off. Spelling mistakes are fine: "opne naukari" is read as "open naukri". Anything else is understood
by the local AI when it is on.

## Opening things

| Example | What happens |
|---|---|
| open chrome, launch vs code, open whatsapp | Opens any app in your Start menu |
| open youtube, open naukri, go to github | Opens the website |
| open youtube in chrome, open naukri using edge | Opens it in that browser |
| go to example dot com | Opens any web address |
| open downloads, open my documents | Opens the folder |
| open windows settings | Opens Windows settings |
| open the pod bay doors | A name it does not know is searched on Google |

Known sites include LinkedIn, Naukri, Indeed, Foundit, Internshala, Glassdoor, Instahyre, Wellfound,
Cutshort, Hirist, Apna, Unstop, GitHub, Stack Overflow, LeetCode, HackerRank, GeeksforGeeks, CodeChef,
Codeforces, Kaggle, Coursera, Udemy, NPTEL, SWAYAM, W3Schools, MDN, YouTube, Gmail, Google Drive, and more.

## SkillPilot

| Example | What happens |
|---|---|
| open my skills, go to tasks, open my resume, open jobs | Opens that screen |
| add task read the guide tomorrow, remind me to call the mentor on friday | Adds a task for that day |
| remind me to call the mentor at 5 pm tomorrow | Adds the task with a reminder: a Windows notification at 5 pm |
| add skill docker, i'm learning typescript | Adds a skill |
| set a goal to get a junior role | Adds a goal |
| mark the guide as done, i finished practise sql | Ticks off the one task that matches |
| what's due today | Lists today's and overdue tasks |
| minimise | Hides the app to the widget |

Days for tasks can be today, tomorrow, a weekday, next Monday, next week, or "in 3 days". Reminder times can be "at 5 pm", "at 9:30 am", or "at 17:30"; a bare "at 5" means 5 pm.
Reminders need **Reminders I set on tasks** on in Settings → Notifications, which it is by default.

## In your own words

With the local AI on, anything else is understood and carried out, for example:

| You say | It does |
|---|---|
| can you pull up naukri for me | Opens Naukri |
| what's the weather in hyderabad today | Google search |
| show me some lofi songs | YouTube search |
| what is the latest version of react | Google search, since the model's own knowledge may be old |
| am i ready for a frontend job? | Answered in the Assistant from your data |
| i want to learn docker | Suggests adding Docker, for you to accept |

Nothing is ever closed, deleted, or bought by voice or text, and anything that would change your data
from an AI guess waits for your approval.
